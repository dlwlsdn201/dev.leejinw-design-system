# 시니어 프론트엔드·디자이너 관점 검토 — Quiet Precision

- 작성일: 2026-10-18
- 대상: `f5a269b` (컴포넌트·토큰은 `origin/main` `2381598`과 동일)
- 성격: 1차 교차 검증(`claude-code-cross-review-result.md`)이 "계약 위반"을 다뤘다면, 이 문서는 **설계 판단의 질**을 다룬다. 20년 동안 바뀌지 않은 기준과 2024–2026년에 바뀐 기준을 구분해 평가하고, 둘이 충돌하면 이유를 적는다.
- 범위: 코드·토큰·카탈로그·PRD 읽기 기반. 브라우저·Figma는 미검증.

## 0. 총평

**잘한 것** — 작은 범위를 지키고, 네이티브 요소를 감싸고, 값의 원본을 하나로 뒀다. 이 세 가지는 디자인 시스템이 1년 뒤에도 살아 있을지 결정하는 요소이며 대부분의 개인 프로젝트가 여기서 실패한다. "6개 컴포넌트에 테마 엔진 없음"은 결핍이 아니라 판단이다.

**아쉬운 것** — 시스템 자체는 절제됐는데, 시스템을 보여주는 **카탈로그가 시스템을 따르지 않는다**. 그리고 한국어 타이포그래피의 기본(`word-break: keep-all`, 자간)을 토큰과 CSS가 다루지 않는다. 한·영 전환을 전제한 시스템에서 이것은 트렌드가 아니라 기본기다.

**지금 해야 하는 이유** — 소비 앱이 0개인 지금이 단위(px→rem)·캐스케이드(`@layer`)·테마 스코프 같은 "되돌리기 비싼 결정"을 바꿀 유일한 시점이다. 1차 보고서에서 "지금 바꾸지 않음"이라고 한 rem 전환은 이 관점에서 **번복**한다. 근거는 §2-1.

## 1. 불변의 기준으로 본 평가

바뀌지 않는 것: 위계·리듬·대비, 네이티브 의미론, 점진적 향상, 단일 원본, 이름의 정직함, 조기 추상화 금지.

| # | 항목 | 평가 | 근거 |
| --- | --- | --- | --- |
| S-1 | 네이티브 의미론 우선 | **좋음** | `button`/`a`/`input`/`textarea`/`label[for]`을 그대로 쓰고 ARIA는 보강용. 단, Checkbox의 `aria-checked`는 네이티브 의미론과 충돌(1차 F-01) |
| S-2 | 한국어 줄바꿈 | **미흡** | `ui.module.css`·`app.css` 어디에도 `word-break: keep-all`이 없다. 한글은 기본값(`normal`)에서 음절 단위로 끊긴다. 라벨·힌트·오류·배지 모두 영향. 긴 영문 URL 대비 `overflow-wrap: anywhere`도 필요 |

| S-7 | 히트 영역 | **좋음** | 44px 터치, coarse pointer 보정, 체크박스 라벨 전체가 클릭 영역. WCAG 2.2 2.5.8(24px 최소)은 넉넉히 충족 |
| S-8 | 포커스 | **좋음** | 2px solid + 2px offset, `:focus-visible`. 2.4.11/2.4.13 충족 가능. 남은 것은 브라우저 확인뿐 |
| S-9 | 단일 원본 | **좋음, 틈 있음** | JSON→CSS 흐름은 옳다. 틈은 1차 F-08(hex↔components 불일치 미감지)과 카탈로그의 `SWATCHES` 배열(`App.tsx:96`)이 hex를 **하드코딩**해 두 번째 원본이 된 것. `tokens.json`을 import해서 표시해야 한다 |
| S-10 | 조기 추상화 금지 | **좋음** | `FieldMessage`·`useFieldIds`만 공유하고 나머지는 중복을 허용. 옳은 선택 |

## 2. 최신 기준(2024–2026)으로 본 평가

| # | 항목 | 평가 | 근거와 제안 |
| --- | --- | --- | --- |
| T-1 | 타입 단위 | **px → rem 전환 권장(번복)** | 브라우저 확대(zoom)는 px도 따라가지만, OS/브라우저 **글꼴 크기 설정**은 rem만 따라간다. 이건 트렌드가 아니라 2010년대부터 합의된 접근성 기준인데, 1차 보고서는 비용 때문에 보류했다. 소비 앱이 없는 지금이 가장 싸다. 생성기에서 `typography.size`·`lineHeight`만 `rem`(÷16)으로 출력하고 간격·모서리·컨트롤 높이는 px 유지 — 이 혼합이 현재 업계 다수 방식 |
| T-2 | 캐스케이드 레이어 | **도입 권장** | `style.css`가 `:root`와 `.클래스`를 레이어 없이 선언하면 소비 앱의 reset(Tailwind preflight, normalize)과 순서 싸움이 난다. `@layer ds.tokens, ds.components;`로 감싸면 소비자가 레이어 바깥에서 쓴 어떤 선언도 이긴다. 비용 거의 0, 2023년부터 baseline |
| T-3 | 테마 스코프 | **지금 준비** | 다크 모드가 v2라도 토큰을 `:root` 대신 `:root, [data-theme="light"]`에 두고 `color-scheme: light`를 선언해 두면 v2는 선택자 하나 추가로 끝난다. `color-scheme`는 네이티브 체크박스·스크롤바·폼 컨트롤 색을 맞추므로 **지금도** 효과가 있다(네이티브 checkbox를 쓰는 시스템에 특히) |
| T-4 | 색 공간 | **보류 적절** | OKLCH/`color-mix()`가 2024년 baseline이 됐고 팔레트 생성에 유리하지만, 토큰이 hex로 고정된 11색뿐인 지금은 이득이 없다. 다크 모드에서 램프를 생성할 때 재검토. DTCG `components`에 srgb 값을 둔 것은 올바른 준비 |
| T-5 | DTCG 2025.10 | **좋음** | `$type`/`$value` 객체형 color·dimension·duration 사용. 아직 안 쓰는 것: `$extensions`로 Figma 스코프 힌트, composite `typography` 토큰. 둘 다 지금 필요 없음 |
| T-6 | React 19 ref | **좋음, 한 곳 개선** | `ComponentPropsWithRef` + ref-as-prop은 정석. Checkbox만 `useEffect`+내부 ref로 `indeterminate`를 다루는데, React 19 ref 콜백 cleanup으로 바꾸면 내부 ref·effect·수동 ref 병합(1차 F-05)이 모두 사라진다 |

## 3. 디자이너 관점 — "절제됨·정교함·명료함"이 실제로 구현됐는가

**절제됨** — 구현됨. 그림자 없음, 강조색 1계열, 테두리 위계(subtle/control) 2단계. 좋다.

**정교함** — 부분적. 정교함은 디테일의 일관성에서 나오는데 아래가 어긋난다.
- 버튼 md 40px ↔ 입력 44px. 같은 줄의 폼에서 높이가 다르다. 입력도 `control.md`를 쓰고 coarse pointer에서만 44로 올리는 쪽이 버튼과 대칭.
- 체크박스는 OS 네이티브(`accent-color`). 실용적이지만 "정교함"을 내건 시스템의 체크박스가 플랫폼마다 다르게 생기는 것은 메시지와 충돌한다. **정책 결정**: 네이티브 유지(접근성·유지비 최소) vs `appearance: none` 커스텀(시각 통제, 상태별 QA 비용). 개인 프로젝트면 네이티브 유지가 맞고, 대신 `color-scheme`으로 색이라도 맞춘다.
- 외부 링크 `↗`를 텍스트로 넣으면 글꼴·크기에 따라 기준선이 흔들린다. 인라인 SVG(`currentColor`, `1em`)가 정교함에 맞다.
- 버튼 `white-space: nowrap`은 한·영 긴 라벨에서 잘림을 만든다. "버튼 라벨은 짧게"는 가이드로 두고 CSS는 줄바꿈을 허용하는 것이 안전.

**명료함** — 구현됨. 라벨 필수, 힌트/오류 분리, 색만으로 상태를 전달하지 않음. 오류가 힌트 아래에 오는 순서는 논쟁이 있지만(오류를 필드 바로 아래로) 현재 순서도 표준 범위.

**카탈로그** — 디자인적으로는 잘 만든 페이지지만 §1 S-3/S-4대로 시스템의 증거가 되지 못한다. 포트폴리오에서 "내 디자인 시스템"을 보여주려면 카탈로그가 시스템으로만 만들어졌음을 보여줘야 설득력이 생긴다. 이것이 이 문서에서 가장 중요한 디자인 지적이다.

## 5. 1차 보고서와 달라진 판단

| 항목 | 1차 | 이번 | 이유 |
| --- | --- | --- | --- |
| px→rem | 지금 바꾸지 않음 | **v1 전에 바꿈** | 글꼴 크기 설정 존중은 트렌드가 아닌 기준이고, 소비자 0명인 지금이 비용 최저점 |
