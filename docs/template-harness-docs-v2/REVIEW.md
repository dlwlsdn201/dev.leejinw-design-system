## 지적사항
> 심각도 정의:
> - **Blocker**: 기능 오동작·데이터 손상·AC 미충족 — 수정 없이 커밋 불가
> - **Major**: 아키텍처 규칙 위반·명백한 버그 가능성·테스트 누락 — 수정 필요
> - **Minor**: 네이밍·주석·사소한 스타일 — 라운드를 돌리지 않고 이월
> ID 규칙: B-n / M-n / m-n. 라운드가 바뀌어도 ID 유지 (해결 추적용).
